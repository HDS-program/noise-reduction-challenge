# 내 목소리를 구해줘! - 음성 잡음 제거

- 팀명: 신호등 (10조)
- 제출 회차: 2
- 제출 버전: 브랜치 hyo-1213257, 태그 submission-2

## 방법
딥러닝·머신러닝을 쓰지 않는 STFT 기반 Wiener 필터입니다. 처리 과정에서 Clean 음성은 사용하지 않고, 입력 파일 하나만 보고 동작합니다.

1. 150 Hz 고역통과 필터로 저역 잡음을 제거합니다.
2. 창 길이 1024(64 ms), hop 256으로 STFT를 계산합니다.
3. 잡음 파워를 파일마다 한 번 추정합니다. 에너지가 낮은 프레임 10%의 평균과, 주파수 칸마다 추정값의 2배를 넘는 값을 빼고 평균을 낸 값(반복 계산) 중 작은 쪽을 씁니다. 조용한 프레임에 섞인 음성 때문에 잡음이 크게 잡히는 것을 줄이기 위한 것입니다.
4. 파일의 75% 이상 구간에서 주변보다 15 dB 이상 강한 주파수 칸을 지속되는 선 모양 잡음(사이렌, 다이얼음 등)으로 보고, 그 칸의 잡음은 시간 중앙값으로 잡고 이득 하한을 0.05로 낮춥니다.
5. decision-directed 방식으로 사전 SNR을 추정해 Wiener 이득을 적용합니다(평활 0.95, 이득 하한 0.2).

파라미터와 구조는 Train 100개 파일의 PESQ로 선택했고, Validation 164개로 확인했습니다.

## 설치와 실행
```bash
pip install -r requirements.txt
python denoise.py --input input --output output
```

input 폴더의 모든 WAV 파일을 처리해 같은 파일명으로 output 폴더에 저장합니다. 샘플링 주파수, 채널 수, 샘플 수는 입력과 같습니다.

## Validation 결과 (164개 파일 평균)
| 방법 | SNR (dB) | PESQ-WB |
|---|---|---|
| Noisy 입력 | 9.6341 | 1.3947 |
| 조교 베이스라인 Wiener (기본 파라미터) | 13.1196 | 1.5984 |
| 1회차 제출 (태그 submission-1) | 13.4683 | 1.7121 |
| 2회차 제출 (태그 submission-2) | 8.0394 | 1.8881 |

2회차에서 SNR이 낮아진 것은 150 Hz 고역통과 때문입니다. 음성의 가장 낮은 성분(기본 주파수 대역)이 함께 줄어 파형 기준 SNR은 떨어지지만, 순위 기준인 PESQ는 저역 잡음 제거 효과로 올랐습니다. 고역통과를 끈 같은 알고리즘은 Validation에서 SNR 12.83 dB, PESQ 1.822였습니다.

## 코드 출처
STFT 처리, 조용한 프레임 기반 잡음 추정, decision-directed Wiener 이득의 기본 구조는 조교가 제공한 베이스라인 노트북의 구현을 기반으로 했습니다. 고역통과 결합, 잡음 추정 보정, 선 모양 잡음 검출은 추가로 구현했습니다.
