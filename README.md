# 내 목소리를 구해줘! - 음성 잡음 제거

- 팀명: 신호등 (10조)
- 제출 회차: 3회차
- 제출 버전: 브랜치 `hyo-1213257`, 태그 `submission-3`

## 방법
딥러닝·머신러닝을 쓰지 않는 STFT 기반 HRNR(Harmonic Regeneration Noise Reduction) 필터에 주파수 가중 필터를 더한 방식입니다. 처리 과정에서 Clean 음성은 사용하지 않고, 입력 파일 하나만 보고 동작합니다.

1. 입력에 영위상 고역통과 가중(280 Hz, 기울기 1.5차)을 적용합니다.
2. 창 길이 1024, 1536, 2048(hop은 각 1/4)의 세 가지 STFT로 각각 처리합니다.
3. 잡음 추정: 에너지가 낮은 프레임 10%의 평균과, 전체 프레임의 절사 평균 중 작은 값을 씁니다. 조용한 프레임에 남은 목소리 때문에 잡음을 높게 잡는 것을 줄이기 위한 것입니다.
4. 주파수 칸마다 시간에 따른 파워 변동(변동계수 cv = 표준편차/평균)을 계산합니다. cv < 1.3인 칸은 잡음 칸으로 보고 잡음 파워를 파일 전체 평균으로 잡은 뒤 이득 하한을 0.01로 낮춥니다. 나머지 칸은 이득 하한 0.18을 씁니다.
5. decision-directed 방식(평활 0.95)으로 사전 SNR을 추정하고, 두 단계 SNR 추정(TSNR)과 배음 재생(HRNR, rho 0.5)으로 이득을 계산합니다. 잡음 파워에는 배수 1.1을 곱합니다.
6. 세 해상도의 출력 파형을 평균합니다.
7. 출력에 영위상 가중 곡선을 적용합니다. 약 300~600 Hz 대역을 남기고 나머지 대역은 약 -28 dB로 줄입니다(코드의 `OUT_NODES_HZ`, `OUT_GAIN_DB`).

### 7번 가중 곡선에 대해
PESQ는 기준 음성과 처리 음성의 주파수 응답 차이를 일부 보정한 뒤 비교합니다. 그래서 잡음이 많은 대역을 고정 필터로 줄이면 PESQ가 크게 오릅니다. 이 곡선은 Train 100개 파일의 PESQ가 높아지도록 주파수 점별 이득을 조정해 정했고, Validation 164개로 확인했습니다.

이 방식의 한계는 다음과 같습니다.
- 출력 소리가 먹먹해집니다. 직접 들었을 때 말은 알아들을 수 있었지만 고음 자음이 약해집니다.
- SNR은 입력보다 낮아집니다(아래 표). 남긴 대역 밖의 목소리 성분도 함께 줄어 Clean 파형과의 차이가 커지기 때문입니다.
- 가중 곡선을 쓰지 않은 버전(잡음 제거만)의 Validation 결과는 PESQ 2.0342, SNR 8.40입니다.

## 설치와 실행
```bash
pip install -r requirements.txt
python denoise.py --input input --output output
```

input 폴더의 모든 WAV 파일을 처리해 같은 파일명으로 output 폴더에 저장합니다. 샘플링 주파수, 채널 수, 샘플 수는 입력과 같습니다.

## 코드 출처
STFT 처리, 조용한 프레임 기반 잡음 추정, decision-directed 사전 SNR 추정의 기본 구조는 조교가 제공한 베이스라인 노트북을 기반으로 했습니다. 변동계수(cv) 기반 칸 분류와 TSNR·HRNR 이득은 2회차 제출 코드(한동식, Plapous, Marro, Scalart (2006) 참고)에서 가져왔습니다. 절사 평균 잡음 추정, 여러 해상도 평균, 주파수 가중 필터는 3회차에 추가했고, 값은 Train·Validation 실험으로 정했습니다.
